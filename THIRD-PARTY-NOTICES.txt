3. FFmpeg - media processing
---------------------------
Original project: https://ffmpeg.org
Source: https://github.com/FFmpeg/FFmpeg

The project's GitHub Actions packages build their own reduced ffmpeg.exe
from unmodified FFmpeg n8.0.3 sources:
https://github.com/FFmpeg/FFmpeg/commit/8ae0b34901ba60a802f183ee75a250a9fc3e09a5

Build configuration:
https://github.com/KeRoDeveloper2026/KeRo-Smarter-Download/blob/main/tools/ffmpeg/build.sh

This configuration uses static linking and --enable-version3, without
--enable-gpl or --enable-nonfree. The resulting FFmpeg build is licensed
under the GNU Lesser General Public License version 3 or later (LGPLv3+).
It includes LAME for MP3 encoding, described separately below.

The build copies the FFmpeg license into tools/ffmpeg-LICENSE.txt.
Source license text:
https://github.com/FFmpeg/FFmpeg/blob/n8.0.3/COPYING.LGPLv3

Alternative FFmpeg downloads:
  build-windows.ps1 and recovery paths can obtain a different prebuilt
  FFmpeg from https://www.gyan.dev/ffmpeg/builds/ when the project's build
  is unavailable. Gyan identifies its main builds as GPLv3, with additional
  bundled libraries under their own terms. The LGPL description above
  applies to this project's reduced build, not to every replacement
