## لغات التطبيق · App interface languages

**لغات الصفحة تختلف عن لغات واجهة البرنامج.** الواجهة الحالية تدعم 8 لغات: العربية، الإنجليزية، الفرنسية، الإسبانية، الألمانية، البرتغالية، التركية والروسية. توفير صفحة صينية أو يابانية أو كورية أو هندية لا يعني إضافة هذه اللغات إلى التطبيق.

**Documentation languages and app languages are separate.** The app currently supports Arabic, English, French, Spanish, German, Portuguese, Turkish and Russian. Chinese, Japanese, Korean and Hindi guides do not imply corresponding app interface support.

## نطاق الصفحات · Coverage

تتضمن الصفحات المترجمة التعريف بالبرنامج، المميزات، روابط المثبّتات الأربعة، اختيار المعمارية، حالة Windows 7 التجريبية، تركيب الإضافات ومعلومات الخصوصية. تبقى التفاصيل التقنية في الأدلة المرتبطة باللغة الأصلية الموضحة على الرابط.

Each localized guide covers the product, features, four installer links, architecture selection, experimental Windows 7 status, extension installation and privacy. Detailed technical documents remain in the language indicated by each link. Arabic and English retain their extended documentation.

## تحديث الترجمات · Maintaining translations

- Keep the release version, installer URLs and package status consistent across all 12 pages.
- Update Arabic and English reference pages and then every affected localized guide when behavior changes.
- Preserve the Windows 7 experimental notice until actual device testing establishes runtime compatibility.
- Keep the distinction between 12 documentation languages and 8 app interface languages.
- Preserve the Firefox 115 ESR guidance for Win7 packages and the unsigned, temporary Firefox installation notice.
- Do not translate executable filenames, commands, folder paths or URLs.
- Free use does not resolve the source-license status; see [license status](README.en.md#license-status).
- Report translation issues through [Issues](https://github.com/KeRoDeveloper2026/KeRo-Smarter-Download/issues), specifying the language and the sentence to correct.
