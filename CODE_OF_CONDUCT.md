# Code of Conduct

## Our pledge

We want participation in KeRo Smarter Download to be a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected behavior

- Be respectful and patient, including with people who are new to the project or to programming.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and its users.
- Write in any language the project supports; if you can, add a short English summary so more people can help.

## Unacceptable behavior

- Harassment, insults, personal attacks, or discriminatory jokes and language.
- Trolling, deliberately derailing discussions, or spamming issues and pull requests.
- Publishing other people's private information, such as cookies, passwords, private links or personal data, without their permission.
- Using the project to promote or request help with illegal activity, such as downloading content you have no right to access.

## Scope

This policy applies in project issues, pull requests, discussions and other community spaces, and when someone officially represents the project.

## Enforcement

The project owner is responsible for clarifying these standards and may remove, edit or reject comments, commits, issues and other contributions that do not follow this Code of Conduct, and may temporarily or permanently ban a contributor for behavior they judge inappropriate.

## Reporting

Report violations to the project owner at [centerinformation2030@gmail.com](mailto:centerinformation2030@gmail.com). Use private GitHub vulnerability reporting only if it is enabled and the report concerns a security vulnerability; see [SECURITY.md](SECURITY.md). Reports will be reviewed fairly, with the reporter’s privacy respected and details shared only as needed to address the incident. Absolute confidentiality cannot be guaranteed.
